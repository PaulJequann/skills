# Skills

Paul Jequann's public skills for AI coding agents. Each directory under
[`skills/`](skills/) follows the [Agent Skills](https://agentskills.io/)
format and can be installed with the Vercel Skills CLI.

```bash
npx skills add PaulJequann/skills --list
npx skills add PaulJequann/skills --skill code-review -g
```

## Development

The files in this repository are the authored source. Installed copies under
`~/.agents/skills` are runtime material managed by the Skills CLI.
