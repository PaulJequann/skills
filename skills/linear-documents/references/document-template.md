# Linear Document Template

Use this compact shape only when creating a new document without a user-supplied
format. Omit sections that do not serve the artifact.

```markdown
## Summary

## Context and evidence

## Decision, plan, or open question

## Validation or next steps

## Scope boundaries

## References

- Related issue, project, repository revision, or external source
```

For ADRs, use `Decision`, `Alternatives considered`, and `Consequences`.
For implementation plans, make `Validation or next steps` concrete and
independently verifiable.
